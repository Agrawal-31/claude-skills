## 4. Pre-filing checklist

```
[ ] Right AY selected (AY = FY + 1); statements all for the same FY
[ ] Residential status worked out; both day counts filled (not 0)
[ ] Form chosen (NR/RNOR never ITR-1); due date for this income type known
[ ] Regime decided (belated -> new only)
[ ] AIS, TIS, 26AS downloaded and reconciled line by line
[ ] Every Indian bank account (incl. closed) listed; refund account pre-validated
[ ] Every sale classified: equity (111A/112A) vs other (112/slab) vs specified MF (slab)
[ ] Purchase dates checked against broker statements (not AIS FMV column)
[ ] Schedule 112A: one AE consolidated row + BE rows; whole rupees
[ ] Table F equals each gain type exactly
[ ] TDS rows: head of income set; full credit claimed
[ ] Exempt NRE/FCNR interest in EI, not OS
[ ] Residents: Schedule FA complete (calendar year), FSI/TR + Form 67 filed if claiming FTC
[ ] Part B-TI and B-TTI match the computation sheet
[ ] Self-assessment tax paid; challan shows in Tax Paid; amount payable 0
[ ] Preview PDF downloaded and reviewed
[ ] E-verification method ready (Aadhaar OTP phone / net banking)
```
